# Esperando Jugadores — Forge 1.19.2

Código fuente de un mod de cliente para Minecraft Java 1.19.2.

Incluye pantalla roja discreta, barra morada, contador, botón Cerrar, tecla F6 y cierre automático al alcanzar la meta.

Para compilar: usa Java 17 y ejecuta `gradle build` en esta carpeta. El JAR debería aparecer en `build/libs/`.
El proyecto incluye GitHub Actions para compilar en la nube.

Este repositorio contiene código fuente, no un JAR ya compilado. La compilación necesita internet para descargar las dependencias.
